# MAKEUP SNIPER — контекст проекта для Claude

Кооп-пати-игра для Steam на 2–4 друзей: один сидит в кресле и видит секретный
референс макияжа, остальные красят его лицо выстрелами (помада-снайперка,
тушь-арбалет, румяна-базука) с 3/8/15 м. Через 60 с — раскрытие в зеркале и
полароид «РЕФЕРЕНС / РЕЗУЛЬТАТ» со % совпадения. Цель — вирусные клипы в TikTok.

Общайся с пользователем по-русски. Он не программист: объясняй простыми словами,
давай короткие пошаговые инструкции, не используй жаргон без пояснения.

## Текущий этап: неделя 1 — локальный прототип без сети

Сделать в Unity 6 (URP), одна сцена, без мультиплеера:
1. Лофт-«коробка»: пол, стены, кресло в центре, три линии стрельбы (3/8/15 м).
2. Голова-болванка Модели: сфера с белым «лицевым холстом» (RenderTexture),
   поворот головы мышью в режиме Модели.
3. Покраска выстрелом: raycast → локальная точка на голове → uv фронтальной
   проекцией (`uv = localHit.xy / faceSize + 0.5`) → штамп кисти в RenderTexture.
   Параллельно логическая сетка 64×64 (цвет-класс + владелец) — только по ней
   считается счёт.
4. Два ствола: помада-снайперка (точка Ø3 см, зум) и румяна-базука (пятно 10 см).
5. Три референса как ScriptableObject с зонами-масками (нос, щёки, губы, глаза):
   Клоун, Панда, След поцелуя.
6. Подсчёт совпадения по зонам (покрытие ≥70% = ✔, штраф за залёт) и экран
   раскрытия с референсом и результатом рядом.
7. Переключение ролей клавишей (стрелок ↔ Модель) для теста в одиночку.

Не делать на этой неделе: сеть, голос, физику снарядов (только аналитические
траектории), больше двух стволов, UI-полировку, ассеты из магазина.

## Технические решения (зафиксированы в GDD, не менять без причины)

- Unity 6 LTS, URP, новая Input System.
- Сеть (с недели 2): FishNet + FishySteamworks, хост-авторитет, снарядов-Rigidbody нет.
- Голос (неделя 3): Steam Voice API, затухание по линиям, lip-sync от RMS.
- Лицо — фронтальная проекция на простой коллайдер, а не UV сложного меша.
- Стиль: яркий пастельный low-poly, персонаж-«яйцо» с большим лицом.

## Правила работы

- Проверяй, что проект компилируется (нет ошибок в консоли Unity) перед тем,
  как объявлять шаг готовым; если не можешь запустить Unity — скажи об этом прямо.
- Небольшие коммиты с понятными сообщениями по-русски или по-английски.
- Папка Unity-проекта: `MakeupSniper/` в корне репозитория. `.gitignore` для
  Unity обязателен (Library/, Temp/, Logs/, obj/, *.csproj, *.sln).
