# MAKEUP SNIPER — контекст проекта для Claude

Кооп-пати-игра для Steam на 2–4 друзей: один сидит в кресле и видит секретный
референс макияжа, остальные красят его лицо выстрелами (помада-снайперка,
тушь-арбалет, румяна-базука) с 3/8/15 м. Через 60 с — раскрытие в зеркале и
полароид «РЕФЕРЕНС / РЕЗУЛЬТАТ» со % совпадения. Цель — вирусные клипы в TikTok.

Общайся с пользователем по-русски. Он не программист: объясняй простыми словами,
давай короткие пошаговые инструкции, не используй жаргон без пояснения.

## Состояние на 02.10.2026: сетевая игра по коду, без голоса

Unity-проект `MakeupSniper/` (Unity 6000.6.3f1, URP), одна сцена
`Assets/MakeupSniper/Scenes/Game.unity`. Недели 1–2 GDD сделаны и сверх плана
добавлено многое из недель 3–6. Пользователь пока не хочет страницу в Steam,
поэтому вход в игру — по коду.

Сделано:
- **Сеть** (FishNet 4.7.3, хост решает всё): `Net/NetSession.cs` — создать игру,
  войти по коду, выйти. Multipass с двумя транспортами: Tugboat (прямой) и
  FishySteamworks (Steam P2P через релей). Код из 8 знаков (`Net/JoinCode.cs`) —
  это IP хоста + порт 7770–7801 + контрольная сумма: локальная сеть, Radmin VPN,
  ZeroTier. Код из 6 букв — комната в лобби Steam (`Net/SteamService.cs`),
  тестовый AppID 480 (Spacewar) до появления своей страницы.
- **Матч** (`Game/Match.cs`, сервер): лобби → выбор образа Моделью → отсчёт →
  стрельба → раскрытие с чаевыми → следующий раунд → итоги вечера. Ротация:
  каждый садится в кресло 1–3 раза; в одиночку Модель — бот.
- **Стволы** (`Data/Weapon_*.asset`): помада-снайперка (зум), тушь-арбалет
  (полоса по направлению полёта), румяна-базука (медленная дуга), тональник-ластик
  (3 заряда, возвращает чистую кожу шейдером `Shaders/EraserBlit.shader`).
- **Модель**: голова мышью, ладонь-щит (ПКМ, 3), уворот (Пробел, выстрел уходит
  «в ухо»), размазать (E, 3), зеркальце на 58% раунда, тайная ставка, запретные слова
  (стрелок жмёт T при нарушении: −5 с), чаевые 100 монет.
- **Очки**: зоны по сетке 64×64 с владельцем и множителем линии (×1/×2/×3),
  «одним выстрелом» +50, в глаз −10, в ухо −5, залёт, «ИДЕАЛЬНО» +30, виноватый
  по цвету фартука. Забрызганный стрелок 6 с видит референс («видение»).
- **Места и прогрессия** (`Data/Location_*.asset`): Лофт → Детский праздник (дети
  ловят выстрелы) → Ресторан: свидание (девушка поднимает глаза, подозрение) →
  Свадьба-босс (невеста + жених, два лица, 90 с). 4 звезды открывают следующее,
  прогресс хранится у хоста (`progress.json`). Задачи «стереть»: в начале раунда на
  лице грязь (засос, чужой поцелуй, вино, торт).
- 17 образов, полароид 1080×1920 сохраняется в «Изображения/MakeupSniper».

Не сделано: голос в игре (играют через Discord), рот-мишень, мегафон, рикошеты,
тест Steam-кода между двумя аккаунтами Steam (код написан, но не проверен).

## Как устроен код

- Всё собирается кодом: меню Unity «Makeup Sniper → Пересобрать сцену»
  (`Scripts/Editor/SceneBuilder.cs`) создаёт сцену, префабы Player и Match, ассеты
  стволов, образов, мест и материалы. Правки сцены вносить туда, а не руками.
- «Makeup Sniper → Собрать игру для Windows» (`Scripts/Editor/BuildTools.cs`) кладёт
  игру в `Builds/MakeupSniper_Windows` (не в git) вместе с `steam_appid.txt` и
  «КАК ИГРАТЬ.txt».
- Лицо: `PaintSurface` (RenderTexture для картинки + `FaceGrid` 64×64 для счёта).
  Фронтальная проекция с отражённой осью x: `uv = (−local.x, local.y) / faceSize + 0.5`,
  иначе картинка на голове зеркальна референсу. Мазок — `StampData`, сервер рассылает
  его всем по порядку, поэтому лицо у всех одинаковое.
- Интерфейс собирается кодом: `UI/GameUI.cs`, помощники `UI/UiKit.cs`.
- Каждый MonoBehaviour/ScriptableObject — в файле со своим именем (иначе сборка игры
  падает при загрузке сцены). Это проверяет тест `ScriptFileNameTests`.

## Как проверять (без окна Unity, проект в редакторе должен быть закрыт)

- `bash tools/verify.sh scene edit play` — пересобрать сцену, тесты EditMode (27)
  и PlayMode (2: тренировочный матч, экскурсия по местам; скриншоты в
  `MakeupSniper/Logs/Shots`).
- `bash tools/verify.sh player net` — собрать игру и сыграть матч двумя копиями по
  сети (`tools/net-test.sh`): хост и гость по коду, каждый по разу Модель; отпечатки
  лица (`hash=`) в отчётах должны совпасть.
- Ключи запуска игры: `-ms-autotest host|join -ms-code КОД -ms-out путь` (автотест),
  `-nosteam` (не трогать Steam). В режиме `-batchmode` Steam не подключается.

## Технические решения (зафиксированы в GDD, не менять без причины)

- Unity 6 LTS, URP, новая Input System.
- Сеть: FishNet + FishySteamworks, хост-авторитет, снарядов-Rigidbody нет
  (аналитические траектории). Пока нет своей страницы Steam — AppID 480 и прямые коды.
- Голос (по плану): Steam Voice API, затухание по линиям, lip-sync от RMS.
- Лицо — фронтальная проекция на простой коллайдер, а не UV сложного меша.
- Стиль: яркий пастельный low-poly, персонаж-«яйцо» с большим лицом.

## Правила работы

- Проверяй, что проект компилируется и тесты проходят, перед тем как объявлять шаг
  готовым; если не можешь запустить Unity — скажи об этом прямо.
- Небольшие коммиты с понятными сообщениями по-русски или по-английски.
- Папка Unity-проекта: `MakeupSniper/` в корне репозитория. `.gitignore` для
  Unity обязателен (Library/, Temp/, Logs/, obj/, *.csproj, *.sln), сборки — в `Builds/`.
- `prototype/index.html` — браузерный прототип, площадка для быстрых проверок идей.
